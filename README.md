Kimi's Visited Places
-
Project Overview
-
This is a web application where Kimi can keep track of the places she has visited. Users can add a place with details like county, landmarks, date, description, and rating. Each place is displayed as a flipping card, with summary information on the front and detailed info on the back. Users can delete entries, and all data persists in localStorage.

Features
-
- Add places with name, county, landmarks, date, description, and rating
- Flipping cards: front shows name & rating, back shows details
- Delete functionality for each place
- Responsive grid layout for form and cards
- Data persists across sessions using localStorage
- Modern and visually appealing styling with hover effects
- Fixed form for easy access while browsing cards


Technologies Used
-
- HTML5: Semantic structure for header, main content, and form
- CSS3: Grid layout, flexbox, hover effects, card flipping animation
- JavaScript (ES6): Object-oriented structure with PlaceManager and Place classes
- LocalStorage: Persist user data across sessions
- Google Fonts: Custom typography


How to Use
-
- Open the index.html file in a browser.
- Fill out the form with your visited place information:
- Name of the place
- County
- Landmark(s)
- Date of visit
- Description
- Rating (1–5)
- Click Add Place.
- The place will appear as a flipping card in the right grid.
- Hover over a card to see details and a Delete button.
- Click Delete to remove a place.
